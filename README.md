# 📖 About the Project

Climate AI Platform is a modern weather intelligence application built with **React**, **TypeScript**, **Vite**, and **Tailwind CSS**.

The platform delivers accurate weather information with AI-powered insights, interactive visualizations, and emergency assistance through a fast and responsive dashboard.

Whether users want to monitor current weather conditions, analyze climate trends, or access emergency information, the platform provides a clean and intuitive experience.

# ✨ Features

- 🌡️ Real-Time Temperature Monitoring

- 🤖 AI-Powered Climate Insights

# 🚀 Getting Started

## Clone the Repository

```bash
git clone https://github.com/bhimannasagar23/Climate_AI_platform.git
```

## Navigate to the Project

```bash
cd Climate_AI_platform
```

## Install Dependencies

```bash
npm install
```

## Start Development Server

```bash
npm run dev
```
