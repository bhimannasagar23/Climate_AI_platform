# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/bhimannasagar23/Climate_AI_platform.git
```

Go into the project

```bash
cd Climate_AI_platform
```

Install dependencies

```bash
npm install
```

Run locally

```bash
npm run dev
```
